Foilwright — ALPS MD-5000/MD-5500 用の仮想プリンタ
====================================================

導入方法
--------
1. この zip をどこか適当な場所に展開する(展開先はどこでもよい。
   導入後は %LOCALAPPDATA%\Foilwright にコピーされるので、この展開先は
   後で消してよい)。
2. あらかじめ Ghostscript を入れておく(同梱していない)。
   https://www.ghostscript.com/ から gswin64c.exe が入るものを選ぶ。
3. PowerShell を「管理者として実行」で開く。
4. 展開した中の install.ps1 を実行する。

   .\install.ps1

   プリンタとポートの作成、自動起動への登録、%LOCALAPPDATA%\Foilwright への
   配置まで自動で行う。何を作ったかは install-manifest.json に記録される。

導入後の使い方
--------------
- 印刷したいアプリケーションで「Foilwright MD-5500」を選んで印刷すれば、
  ホワイトボード上のトレイアプリが受け取って処理する。
- 通常起動時にトレイアプリが自動で立ち上がる(タスクトレイに常駐する)。

取り除き方
----------
展開した中の uninstall.ps1 を実行する(管理者として実行が要る場合がある)。

  .\uninstall.ps1

install.ps1 が作ったもの(プリンタ・ポート・自動起動の登録・配置した
実行ファイル一式)だけを取り除く。設定ファイル(パレット・用紙定義など)は
既定で残る。設定ごと全部消したいときは -Purge を付ける。

  .\uninstall.ps1 -Purge

何を消すかだけ確認したい場合は -WhatIf を付ける。

  .\uninstall.ps1 -WhatIf

設定ファイルについて
--------------------
%LOCALAPPDATA%\Foilwright の下にある以下のフォルダ・ファイルは利用者が
編集してよいものである(取り除いても既定では残る):

  palette\    インクの発色定義
  profiles\   機種ごとのプロファイル
  papers\     用紙寸法表
  media.yaml  用紙種別の定義
  colour\     色補正データ

不具合の報告
------------
このソフトウェアは開発中である。挙動がおかしい場合は、印刷しようとした
ファイルと、そのときの状況を添えて報告してほしい。
